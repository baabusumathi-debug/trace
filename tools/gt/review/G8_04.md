# G8_04 fact-check log

All 12 keys agree. Picks checked against papers.json, and all match (Trace/HT). No cardfix entries.

- **GT8-61** Transplant rejection: dropped the weak link D05A|IC-08 (it is an infection matrix and does not teach rejection treatment). Facts unchanged (KDIGO 2009: steroids first for acute cellular rejection, lymphocyte-depleting antibody if steroid-resistant; IL-2RA induction by default, ATG for high risk).
- **GT8-64** Brain death apnoea test: rewrote the "inconclusive" paragraph, option D and the key note. Under the 2023 guideline the result has not met criteria (protocols call it "indeterminate"). If the patient is stable, the test can be continued with serial ABGs or repeated; ancillary testing is an option, not mandatory. Criteria: PaCO2 ≥60, a rise of ≥20 and pH <7.30. Sources: https://uab.edu/medicine/surgery/images/Trauma_and_Acute_Care_Surgery/Protocols/Brain_Death_Policy_011325.pdf ; https://www.msdmanuals.com/professional/multimedia/table/guidelines-for-determining-brain-deathdeath-by-neurologic-criteria-in-patients-37-weeks-old
