# Trace

Naven's offline card cabinet for NEET-SS Critical Care. Installable web app (phone, Galaxy Tab S10 Ultra, Mac).

- Cards and progress live in Naven's own Google Drive / Sheet. Nothing private is stored in this repository.
- Each device connects once through a private setup link; after that the app works offline and syncs by itself.
- `backend/Code.gs` is the Apps Script bridge (the deployed copy holds the private key; this copy has a placeholder).

**Working on this repo (any AI assistant or person): read [AGENTS.md](AGENTS.md) first.** Changes are logged in [CHANGELOG.md](CHANGELOG.md).
